How LIDAR (Light Detection and Ranging) works​
- Lasers constantly emit light out in every direction​
- When the light hits an object, it bounces back after some time​
- It uses these things to calculate how far things are in the surrounding area​
- The result is a 3D model of the area that the lasers have been shooting at

How LIDAR Module Works in PiRail​
- Created 2023
- Created with the idea of detecting objects close to the track, seeing if they are "hard" or "soft" objects, and deciding if these objects would be a problem in the future​
- Currently not being worked on​
- Could be used in the future to decide on which areas should be indicated as POIs
